Urban Pulse.

A smart-city monitoring concept that combines Arduino sensors with a connected interface to monitor air quality, gas levels and environmental noise.

Arduino UnoHC-05 BluetoothMQ-2 Gas SensorNoise SensorLCDIoT

Project info

  • Reads environmental sensor values through Arduino analog inputs.
  • Sends live readings over Bluetooth to a connected phone interface.
  • LCD provides an on-device status view while the buzzer can act as an alert.
  • Designed as a modular base that can later add AQI calculations and charts.

Project pictures

Materials needed

•Arduino Uno
•HC-05 Bluetooth module
•MQ-2 gas sensor
•Noise sensor
•16×2 LCD
•Buzzer
•Jumper wires + breadboard
